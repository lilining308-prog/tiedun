1. 全部 28 个 Kotlin 文件、AndroidManifest.xml、19 个 res/ 资源文件、docs/、README、promo/、构建脚本、assets/ 合规文档均为本项目原创/自写，无第三方代码、布局、图标或素材的复制与改写。

4. 版权人（liyan）为全部原创代码的著作权人，有权自行更换主许可证为 MulanPSL-2.0。
5. 唯一不可变更的事实：已按 GPL-3.0 分发的历史版本（deliverables/、apk/ 下既有二进制与源码包）的授权永久有效、不撤销，其源码提供义务按当时条款继续履行；仅新版本换标。

## 3. 核心机制对比（设计参考 ≠ 复制）

| 能力 | 上游实现 | tiedun 实现 | 判定 |
